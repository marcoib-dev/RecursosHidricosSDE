## 🎯 Problema: Si la BD no funciona

### Causas más comunes:

| Problema | Síntoma | Solución |
|----------|---------|----------|
| **MySQL no ejecuta** | Error `ECONNREFUSED` | Iniciar servicio MySQL |
| **Contraseña incorrecta** | Error `ER_ACCESS_DENIED_ERROR` | Verificar `.env` |
| **BD no existe** | Error `ER_BAD_DB_ERROR` | Ejecutar `npm run db:init` |
| **Host incorrecto** | Error `ENOTFOUND` | Cambiar `DB_HOST` en `.env` |

---

## 🔧 Solución Rápida (5 pasos)

### 1️⃣ Asegúrate que MySQL está corriendo

**Windows:**
```powershell
# Como Administrador
Start-Service MySQL80
```

**Linux/Mac:**
```bash
sudo systemctl start mysql
```

### 2️⃣ Ejecuta el diagnóstico

```bash
cd backend
node diagnostico-bd.js
```

### 3️⃣ Si hay error, sigue el script

El script `diagnostico-bd.js` te dirá exactamente qué hacer.

### 4️⃣ Reinicia servidores

```bash
# Terminal 1
cd backend && npm run dev

# Terminal 2
cd frontend && npm run dev
```

### 5️⃣ Accede a la app

Abre: `http://localhost:3000`
