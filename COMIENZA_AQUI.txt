🆘 MI MYSQL NO ESTÁ CORRIENDO
───────────────────────────────

Este es el problema #1 de todos. Soluciona así:

Windows:
┌────────────────────────────────────────────────────────────────┐
│ 1. Win + R                                                     │
│ 2. Escribe: services.msc                                       │
│ 3. Busca: MySQL80 (o cualquier servicio que diga MySQL)       │
│ 4. Click derecho > Start                                       │
│ 5. Espera 5 segundos                                           │
│ 6. Vuelve a la terminal y prueba de nuevo                      │
└────────────────────────────────────────────────────────────────┘

Linux:
┌────────────────────────────────────────────────────────────────┐
│ sudo systemctl start mysql                                     │
│ sudo systemctl status mysql  (para verificar)                  │
└────────────────────────────────────────────────────────────────┘

Mac:
┌────────────────────────────────────────────────────────────────┐
│ brew services start mysql                                      │
│ brew services list | grep mysql  (para verificar)              │
└────────────────────────────────────────────────────────────────┘

❓ PREGUNTAS FRECUENTES
──────────────────────

P: ¿Por qué me dice que MySQL no está conectado?
R: MySQL no está ejecutándose. Ve a "Mi MySQL no está corriendo" arriba.

P: ¿Qué es el script diagnostico-bd.js?
R: Una herramienta que verifica todo automáticamente y te dice qué falta.

P: ¿Puedo usar estos scripts en mi máquina?
R: Sí, son genéricos. Windows, Linux, Mac - todos funcionan.

P: ¿Cómo comparto esto con mis compañeros?
R: Envía: REPORTE_FINAL_BD.txt + README_SETUP.md + DIAGNOSTICO_BD.md

P: ¿Mi contraseña de MySQL es diferente?
R: Cambia DB_PASSWORD en backend/.env al valor correcto.

P: ¿Puedo cambiar los puertos 3000 y 4000?
R: Sí, modifica frontend/vite.config.js y backend/.env

P: ¿Necesito internet?
R: No, funciona completamente local.
