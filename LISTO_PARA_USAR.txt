❌ "ERR_CONNECTION_REFUSED en puerto 3000"
✅ SOLUCIÓN: El frontend no está corriendo. Ejecuta:
   cd frontend && npm run dev

❌ "Error conectando a MySQL"
✅ SOLUCIÓN: 
   1. Verifica que MySQL esté corriendo (Win+R > services.msc)
   2. Verifica las credenciales en backend/.env
   3. Ejecuta: node backend/verify-users.js para diagnosticar

❌ "Credenciales inválidas al hacer login"
✅ SOLUCIÓN:
   1. Verifica que escribiste bien el email y contraseña
   2. Ejecuta: node backend/verify-users.js
   3. Si los usuarios no existen, ejecuta: npm run db:init

❌ "Puerto 3000/4000 ya está en uso"
✅ SOLUCIÓN:
   1. Cambia el puerto en .env (backend) o vite.config.js (frontend)
   2. O mata el proceso: Get-Process node | Stop-Process -Force

❌ "Sesión expirada después de hacer login"
✅ SOLUCIÓN:
   1. Abre la consola del navegador (F12)
   2. Limpia localStorage: localStorage.clear()
   3. Recarga la página: location.reload()
   4. Intenta login de nuevo
