┌─ 🚦 GUÍA RÁPIDA POR SITUACIÓN ────────────────────────────────────────────────┐

  ¿Qué hago si...?

  ❓ "Acabo de clonar el proyecto"
     → Lee: README_SETUP.md
     → Ejecuta: npm install (en backend y frontend)
     → Verifica: node backend/diagnostico-bd.js

  ❓ "MySQL no funciona"
     → Lee: DIAGNOSTICO_BD.md (sección MySQL)
     → Windows: Start-Service MySQL80
     → Linux: sudo systemctl start mysql

  ❓ "La BD no existe"
     → Ejecuta: npm run db:init (en backend)
     → Opcional: npm run db:seed (para datos de prueba)

  ❓ "Contraseña incorrecta"
     → Verifica: backend/.env (DB_PASSWORD)
     → O cambia: ALTER USER 'root'@'localhost' IDENTIFIED BY 'nueva_pw';

  ❓ "El puerto 3000 está ocupado"
     → Cambia en: vite.config.js (frontend)
     → O detén lo que use ese puerto

  ❓ "Quiero compartir con compañeros"
     → Envía: REPORTE_FINAL_BD.txt
     → Adjunta: DIAGNOSTICO_BD.md y README_SETUP.md
     → Diles: Ejecuten node backend/diagnostico-bd.js

  ❓ "Necesito entender la estructura"
     → Lee: Este índice (INDICE.txt)
     → Explora: Las carpetas mencionadas
     → Estudia: Los archivos .js y .jsx

  ❓ "Algo no funciona y no sé qué es"
     → Ejecuta: node backend/diagnostico-bd.js
     → Copia: Todo el output
     → Contacta: Con el output completo
